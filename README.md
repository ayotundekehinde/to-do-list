# To-Do List

A simple to-do list app built with HTML, CSS, and JavaScript.

## Project goal

This project is meant to be built gradually, one small feature at a time. Each step is designed to help a beginner understand the core ideas behind front-end web development without overwhelming them.

## Stack

- HTML for structure
- CSS for styling
- JavaScript for interactivity

## Current features

- Add a new task
- Delete a task
- See tasks appear in the list

## How to run it locally

From the project folder, start a simple local web server:

```bash
python3 -m http.server 3000
```

Then open this in your browser:

```text
http://localhost:3000
```
